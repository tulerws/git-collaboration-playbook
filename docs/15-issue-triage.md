# Issue triage

Triage turns incoming reports into work that can be understood and prioritized.

- Confirm the expected and observed behavior.
- Ask for the smallest reproducible example when evidence is missing.
- Label impact, area, and urgency consistently.
- Link duplicates to one canonical issue.
- Close requests only with a brief reason and a useful next step.

Assign an owner only when the team has agreed to act on the issue.
